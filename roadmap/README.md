# Roadmap

This directory contains implementation roadmaps for QLabs Workbench MCP.

Roadmap files are planning artifacts for agents and maintainers. They do not
ship as runtime source and should record current evidence, known gaps, task
breakdowns, acceptance criteria, and verification commands.

When editing roadmap files, preserve any baseline notes about dirty worktrees or
pre-existing changes so later agents do not overwrite work that was already in
progress.
